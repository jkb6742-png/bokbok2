# 구조·제목 지문 공용 규격 (fp-1.0)

bokbok G2(`quality/`)와 LOGMETER가 같은 값을 내도록 맞춘 규격. 구현은 `quality/fingerprint.js`.
- `structureFromBlocks(blocks)`: 의존성 없는 순수 함수(LOGMETER는 이 함수를 그대로 `require` 한다)
- `FINGERPRINT_VERSION = 'fp-1.0'`: 규칙을 바꾸면 버전을 올리고 회귀 기준값을 새로 잡는다

## 1. 블록 문자

| 문자 | 뜻 |
|---|---|
| P | 일반 문단 |
| H | 소주제(## 줄, 소제목으로 쓰인 인용구) |
| Q | 소제목이 아닌 인용구 |
| T | 표 |
| I | 사진(이미지 1장 = I 1개) |
| D | 구분선 |
| L | 목록(✔ · • - 1. 등으로 시작하는 줄이 문단의 절반 이상, 2줄 이상) |
| X | 해시태그 블록 |

입력: `[{ type: 'P'|'H'|'Q'|'T'|'I'|'D'|'L'|'X', text? }]`. 대소문자 무관. 위 8개 외의 요소(링크 카드, 지도, 동영상, 스티커 등)는 버린다.

## 2. 정규화

- **연속된 P는 P 하나로 합친다. 연속된 L도 L 하나로 합친다.** (H·Q·T·I·D·X는 합치지 않음)
  - 이유: 원고의 `[빈줄]` 문단 나누기와 네이버 에디터의 문단 나누기가 1:1로 대응하지 않는다. 합쳐야 원고와 발행 글이 같은 지문을 낸다.
  - 참고: 합치기 전 방식에서 ENFP 궁합↔미루는 습관 LCS = 0.875 (GPT 측정 0.873과 일치), 합친 뒤 0.818.

## 3. 원고·에디터 요소 → 블록

| 원고(.txt / layout.js) | 네이버 에디터(발행 글) | 블록 |
|---|---|---|
| 본문 줄 묶음(빈 줄로 나뉜 문단) | 텍스트 컴포넌트 문단 | P (연속 병합) |
| `## 소주제` | 소제목·굵은 단독 제목 컴포넌트 | H |
| `> 인용구` 중 40자 이하이면서 `1.`·`Q.`·`A.`로 시작 / `?`로 끝남 / 이모지로 시작 / 24자 이하 | 같은 조건의 인용구 컴포넌트 | H |
| 그 밖의 `> 인용구` | 인용구 컴포넌트 | Q |
| `[표]…[/표]` | 표 컴포넌트 | T |
| `[사진]` | 이미지 컴포넌트(이미지 묶음은 장 수만큼) | I |
| `---` | 구분선 컴포넌트 | D |
| ✔ · • 줄이 절반 이상인 문단 | 목록 컴포넌트 | L |
| `[해시태그]` | 본문 끝 태그 영역 | X |
| `[링크]` | 링크 카드 | (버림) |

## 4. 구조 유사도(LCS)

`structureLcs(a, b) = LCS(a, b) / max(len(a), len(b))` — 문자 단위 최장 공통 부분수열.
G2 기준: 같은 블로그 최근 3편 중 2편 이상이 0.80 이상이면 `STRUCTURE_CLUSTER`(REWRITE). 이력이 3편 미만이면 `DATA_UNKNOWN`.

## 5. 제목 패턴

1. NFKC, 서식 표시 제거
2. MBTI 유형(`[EI][NS][TF][JP]`)과 별명(인팁·엔프피·잇프피 등 16개) → `{t}` (뒤 조사는 유지: `INTP가` → `{t}가`)
3. 숫자 → `{n}` (`5가지` → `{n}가지`)
4. 공백과 구분자 `| , ? ! · : ~ …` 및 끝 마침표로 토큰 분리(구분자도 토큰으로 유지), 소문자화

비교 `titleSim(a, b)`: 두 제목이 공유하지 않는 낱말 토큰은 `{w}`로 바꾸고 연속 `{w}`는 하나로 접은 뒤, 가중 LCS / 최대 길이. 같은 토큰 일치는 1점, `{w}`끼리 일치는 0.5점.
예: `ISTP 특징 | 말없이 고쳐놓는 잇팁, INTP가 옆에서 본 5가지 모습` ↔ `ISFP 특징 | 말보다 취향으로 말하는 잇프피, …` = 0.955.
G2 기준: 최근 5편 중 2편 이상 0.85 이상이면 `TITLE_PATTERN_REPEAT`(REWRITE).

## 6. LOGMETER 이력 항목

`{ source: 'logmeter', title, titlePattern, structure, publishedAt, logNo, fingerprintVersion }` 만 보낸다. 본문 벡터가 없으므로 G2는 이 항목을 제목 패턴·구조 LCS로만 비교하고, 본문 유사도는 `TEXT_SIMILARITY_UNKNOWN`으로 표시한다.
